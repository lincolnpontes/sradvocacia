# SR Advocacia 1.0.49

## Documentos

Em **Configurações > Usuários**, edite o perfil da advogada. Habilite **Documentos** para abrir a biblioteca e **Clientes** para preencher novas minutas com os dados do cadastro. Perfis existentes não recebem automaticamente a nova permissão.

1. Escolha procuração judicial, contrato de honorários ou recibo, selecione o cliente e clique em **Gerar cópia**.
2. Revise os dados, substitua os campos entre colchetes e edite o texto. A cópia é independente: editar a minuta não altera o cadastro, o modelo original nem o financeiro.
3. Confirme a revisão para baixar o Word ou imprimir. Para PDF, use **Salvar como PDF** no diálogo de impressão. Uma edição invalida a revisão; a confirmação não constitui assinatura eletrônica.

Os rascunhos são salvos no navegador deste aparelho, por perfil e escritório. Não são enviados ao Apps Script, ao Google ou a um serviço externo, nem fazem parte do backup geral do banco sincronizado. Baixe o rascunho em texto para manter uma cópia fora do aparelho; não limpe os dados do navegador para atualizar. Em caso de conflito entre abas, guarde uma nova cópia em vez de sobrescrever a revisão existente.

## Instalação

Na tela de login, use **Instalar aplicativo**. Quando o navegador disponibiliza a instalação nativa, a confirmação é feita por ele. No iPhone/iPad, use o menu de compartilhamento; no Safari compatível do Mac, use **Adicionar ao Dock**. Em modo aplicativo o botão fica oculto. Não é necessário informar a senha do escritório para instalar.

A URL do Apps Script e o protocolo do banco continuam inalterados. Esta versão não integra nem autoriza Google Agenda ou Jusbrasil.
